# quiz-helper · 答题助手

**一个单文件的 Tampermonkey 用户脚本：把整套题交给 AI 判，再按站点自己的格式写回去。**

> **适用平台：易智教云课堂（`csgmooc.com`）**
> 安装后在 `https://www.csgmooc.com` 的任务页 / 答题页运行；其他平台不适用。

## 能做什么

- **整卷作答**：单次读取整套题，分批交给 AI，按题型校验后写回。
- **题型覆盖**：单选、多选、判断、填空、连线、主观题；代码 / 排序等做不了的整套跳过。
- **多家 AI**：DeepSeek / OpenAI / Claude / Gemini / Kimi / 智谱 / 通义 / 火山 / 硅基流动 / OpenRouter / 本机 Ollama / 自定义。
- **模型自检**：设置里「检测模型」列出这把 Key 能用的型号，「测连通」发一条最小请求。
- **本地题库**：命中就不调 AI；交卷后按官方判定自动学习。
- **节奏控制**：逐题停顿、延迟交卷、两套之间随机间隔。
- **无人值守**：打开任务页自动跑，支持上限、重试、范围锁。
- **跳过规则**：命中「拍照上传」「谈谈你的感想」这类规则时，不调 AI、不写、不交。

## 三分钟上手

1. 安装 Tampermonkey。
2. 把 `csgmooc-helper.user.js` 拖进浏览器窗口 → 点「安装」。
3. 打开站点并登录，右下角会出现「AI 易智教助手」。
4. 点「设置」→ 选服务商 → 填 Key → 点「检测模型」挑一个 → 保存。
5. 回到任务页，点卡片上的「AI 自动作答」。

> 图片版试卷需要能看图的模型；设置里的「图片模型」留空表示和主模型同一个。

## 支持的题型与答案格式

| 题型 | 写法 |
|---|---|
| 单选 / 判断 | `A` |
| 多选 | `ABD`（按选项顺序直接相连） |
| 填空 | `a#CSG#b#CSG#c`（按空顺序） |
| 连线 | `1C#2A#3G`（左序号 + 右字母） |
| 主观题 | `<p>…</p>` 富文本，DES-ECB 加密后提交 |

写入前会按题型校验：字母越界、配对数不对、填空段数不符，一律拒绝，不会把错答案落库。

## 边界

- Key、题库、做题记录都只存在本机浏览器里，不会上传到别处。
- AI 只收到题干 / 试卷图片，不发送账号、密码、学号。
- 代码题、排序题等未支持题型会整套跳过，避免瞎写。
